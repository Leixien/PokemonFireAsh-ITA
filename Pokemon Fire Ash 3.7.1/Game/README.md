# Dev Files for Pokémon Fire Ash.

## Rules for forking
Contributions are valued and are welcomed, but first please message Luc-ker on Discord (luc_ker5414) with the following:
- Functionality to add or issue to fix
- Estimate of time it will take

This is so that you can have the most up-to-date version of the dev files, as well as allow Luc-ker to handle your pull request easier.
If these steps aren't followed, Luc-ker reserves the right to ignore any pull requests.
